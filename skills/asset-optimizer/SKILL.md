# Asset Optimizer

Read the extraction manifest. Select desktop and mobile dimensions, format and quality within the project byte budget. Preserve deterministic filenames. Produce an asset manifest containing per-frame bytes and dimensions. Mark all byte savings as measured only when both source and output sizes were read from disk.
