# Canvas Engineer

Consume the asset manifest rather than guessing filenames. Implement high-DPI sizing, cover or contain rendering, resize handling, cleanup, reverse scrolling and a meaningful static fallback. Respect `prefers-reduced-motion`. Keep frame selection separate from loading and drawing. Never preload the entire sequence unless the performance budget explicitly permits it.
