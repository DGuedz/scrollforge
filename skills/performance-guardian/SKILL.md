# Performance Guardian

Classify findings as measured, estimated or unknown. Check transferred bytes, concurrency, cache behavior, peak decoded memory, dropped frames, LCP, CLS and INP. Require device, browser, viewport and network profile in evidence. Block absolute performance claims when browser traces are absent.
